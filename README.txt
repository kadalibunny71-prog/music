FORGE FITNESS WEBSITE

Files
- index.html: webpage structure and content
- style.css: layout, colors, responsive design and visual styling
- script.js: mobile menu, membership selection and registration form interaction

How to run
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Double-click index.html, or open it with Chrome/Edge.

Notes
- The website uses online Google Fonts and Unsplash images, so an internet connection is needed for those assets.
- Registration is a front-end demo. It validates the form and displays a confirmation, but does not send or store registrations. To collect real registrations, connect a backend or form service.
- Membership prices and trainer details are sample content. Change them in index.html to match your project.
